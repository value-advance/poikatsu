Joshin webショップとは?特徴とポイントの貯め方をわかりやすく解説

作成日:2026.07.20 更新日:2026.09.24

「Joshin webショップ」は、株式会社Joshin(家電量販店ジョーシン)が運営する、家電・パソコン・ホビーなどの通販サイトです。ジョーシンポイントは店舗とJoshin webショップで共通して貯めたり使ったりできますが、価格・進呈ポイント・送料などの販売条件は店舗と異なります。この記事では、Joshin webショップの特徴やポイントの貯め方に加え、購入前に確認したい送料・店舗受取・支払い方法の基本情報を、2026年9月24日時点の公式情報をもとに整理します。

Joshin webショップは、家電やゲーム、おもちゃなどを中心に取り扱う通販サイトです。店舗とネットでポイントを共通利用でき、貯まったポイントは1ポイント=1円として使えます。

ジョーシンポイントと店舗との関係

  • ポイントは店舗とネットで共通1ポイント=1円として、Joshin webショップとジョーシングループ各店舗で相互に貯めたり使ったりできます。会員ページ(my Joshin)にジョーシンカード番号を登録するだけで相互利用でき、新規会員登録の直後などは、すぐに使えない場合があります
  • 共通利用の対象はJoshin webショップのみ「Joshin web 楽天店」「Joshin web Yahoo!ショッピング」などでは、ポイントの相互利用はできません
  • 店舗とWebで販売条件は異なります価格・進呈ポイント・取扱商品・送料が店舗と異なり、Joshin webショップの価格と進呈ポイントは、セルフでのweb販売を前提とした特別価格とされています。ポイントを共通で使えても、店舗とWebで同じ価格・同じ還元になるとは限りません。なお、Joshin webショップではクレジットカードで支払っても進呈率は変わらず、店舗では進呈ポイントが減額されると案内されています
  • 進呈率は一定ではありません商品によって異なり、おおむね0〜20%です。値引き商品にはポイントが付かない場合があります。進呈ポイントは商品ページの「会員様web価格」の下や、カート内で確認できます
  • 有効期限通常ポイントは、ジョーシンカードの最終利用日から1年間(翌年同月末まで)有効で、期間内にカードを利用するとその時点から累計ポイントの有効期限が延長されます。期間限定ポイントは、当社が指定した期間のみ有効です
  • 他社ポイントとは別の制度ですジョーシンポイントは独自のポイントです。dポイントはJoshin webショップでは使えません(ジョーシン各店舗や「Joshin web dショッピング店」では利用できます)。楽天ポイントは、支払い方法で「楽天ペイ」を選択した場合に使えます(利用可能な残高が50ポイント以上必要です)

購入前に確認したい送料・店舗受取・支払い方法

以下は2026年9月24日時点の公式サイトの案内です。送料などの条件は変更される場合があるため、購入前に公式サイトでご確認ください。

  • 会員登録Joshin webショップでのお買い物には会員登録が必要です。ジョーシンカードをお持ちでない方は、会員入会時にジョーシンカード(クレジットカード機能なし)が新規発行されます。すでにお持ちの場合は、カード番号を会員ページに登録します
  • 送料(家電・ホビー商品)2026年9月24日時点では、税込2,980円以上のご購入で送料無料、2,980円未満は550円(税込)です(沖縄・一部地域を除く)。ゴールドスマイル以上の会員は、税込1,980円以上で送料無料になります。公式FAQでは「今なら」と案内されている条件で、送料条件は変更される場合があるため、注文前に公式サイトで最新条件をご確認ください
  • 送料(音楽/映像ソフト・書籍)2026年9月24日時点では、1回税込1,980円以上で送料無料、未満は390円(税込)です。こちらも変更される場合があります
  • 送料の注意点送料は、webクーポンやポイントを利用する前の購入金額で判定されます。沖縄県へのお届けは追加料金(2,000円・税込)がかかります(音楽・映像ソフトを除く)。設置や工事が必要な商品は別途費用がかかる場合があるため、商品ページや公式のご案内で確認してください
  • 店舗受取対象商品に限り、注文時に「ジョーシン店舗で受け取り」を選んで受取店舗を指定できます。対象商品には「店舗受け取りが可能です」と表示され、受取できる店舗のみが一覧に表示されます。商品は注文後に店舗へ移動するため、受取可能になるまで日数がかかり、準備ができると会員登録のメールアドレスに連絡があります。受取店舗の変更や、自宅配送への変更はできません(変更する場合は、キャンセルして再注文)
  • 支払い方法クレジットカード・銀行振込・電子マネー・コンビニ決済・PayPayオンライン決済・楽天ペイ・au PAY・ポイント/クーポン・ギフトカード/プリペイドカードから選べます。手数料などの詳細は公式のお支払い方法ページで確認してください

よくある質問

店舗で貯めたポイントをネットで使えますか?

はい。ジョーシンカード番号を会員ページ(my Joshin)に登録すれば、1ポイント=1円として店舗とJoshin webショップで相互に貯めたり使ったりできます。ただし相互利用の対象はJoshin webショップのみで、楽天店やYahoo!ショッピング店では利用できません。

家電以外も購入できますか?

パソコンやゲーム・おもちゃなどのホビー、音楽/映像ソフト、書籍なども取り扱っていますが、幅広いジャンルをまとめ買いしたい場合は他サイトとの併用がおすすめです。

Joshin webショップの送料はいくらですか?

2026年9月24日時点では、家電・ホビー商品は税込2,980円以上で送料無料、未満は550円(税込)です(沖縄・一部地域を除く)。音楽/映像ソフト・書籍は税込1,980円以上で送料無料です。送料条件は変更される場合があるため、注文前に公式サイトで最新条件をご確認ください。

Joshin webショップで注文した商品を店舗で受け取れますか?

店舗受取サービスの対象商品に限り、注文時に「ジョーシン店舗で受け取り」を選択できます。すべての店舗・商品が対象ではなく、受取可能になるまで日数がかかります。
